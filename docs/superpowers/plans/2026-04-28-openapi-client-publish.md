# `uptrakit-openapi-client` Self-Containment Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development
> (recommended) or superpowers:executing-plans to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Remove all 3 workspace path dependencies from `uptrakit-openapi-client` and set
`publish = true` so it can be published to crates.io.

**Architecture:** (A) Add a `--features dump-openapi` binary target to `uptrakit-web-api` that
writes the full OpenAPI JSON spec to stdout; commit the initial `openapi/spec.json`. (B) Add a
`sync-openapi-client` command to the existing xtask crate (from the service-sdk plan) that
regenerates `src/generated/` from `openapi/spec.json` using the `progenitor` crate; update all
import sites in openapi-client. (C) Inline `impl_report_conversion!` and remove the remaining
workspace path deps; set `publish = true`. (D) Add CI + pre-commit guards.

**Prerequisite:** The service-sdk plan (`2026-04-28-service-sdk-publish.md`) must be complete
because this plan extends the xtask crate that plan creates.

**Tech Stack:** Rust, `progenitor` (OpenAPI → Rust client codegen), `utoipa` (already used by
`uptrakit-web-api`), xtask (extended from service-sdk plan), `anyhow`.

---

## Context

`uptrakit-openapi-client` lives at `crates/shared/openapi-client/`. It currently has these
workspace path deps:

| Dep | How used | Resolution |
| --- | --- | --- |
| `uptrakit-shared-macros` | `impl_report_conversion!` in `error.rs` only | Inline the macro in a private `src/macros.rs` |
| `uptrakit-shared-types` | `DeviceAuthStatus` (re-exported), `ServiceStatus` (tests), `PluginRole` (tests), `plugin_ids` (tests) | Generate `DeviceAuthStatus`/`ServiceStatus`/`PluginRole` from OpenAPI spec via codegen; `plugin_ids` stays test-only and can be duplicated inline |
| `uptrakit-web-api-types` | Used throughout — re-exported as `pub use uptrakit_web_api_types as types;` and used in all 39 endpoint modules | Replace with generated types from `src/generated/` |

The openapi-client currently re-exports `uptrakit_web_api_types as types`. External consumers
use `uptrakit_openapi_client::types::*`. After this plan, `types` points to
`crate::generated::types` instead — the re-export path is unchanged.

`uptrakit-web-api` already serves the full OpenAPI spec at `/api/openapi.json` at runtime (via
utoipa). We add a `dump-openapi` feature that instantiates `ApiDoc` and prints it to stdout
without starting the server, so CI can regenerate `openapi/spec.json` from source. The canonical
spec must be generated with all features: `db-all,oidc,nats,notifications-all,zeroconf`.

`progenitor` generates a typed client from an OpenAPI spec. We use `progenitor-client` (the
runtime library) + a build step in xtask to emit Rust code into `src/generated/`.

- [ ] **Step 2: Create `xtask/src/sync_openapi_client.rs`**

```rust
use anyhow::{Context, Result, bail};
use std::{fs, path::Path};

pub fn run(workspace_root: &Path, check: bool) -> Result<()> {
    let spec_path = workspace_root.join("openapi/spec.json");
    let out_path = workspace_root
        .join("crates/shared/openapi-client/src/generated/types.rs");

    let spec_str = fs::read_to_string(&spec_path)
        .with_context(|| format!("reading {}", spec_path.display()))?;

    let spec: openapiv3::OpenAPI = serde_json::from_str(&spec_str)
        .context("parsing OpenAPI spec")?;

    let mut settings = progenitor_generator::GenerationSettings::default();
    settings.with_interface(progenitor_generator::InterfaceStyle::Positional);

    let mut generator = progenitor_generator::Generator::new(&settings);
    let tokens = generator.generate_tokens(&spec)
        .context("generating client code")?;

    let ast: syn::File = syn::parse2(tokens).context("parsing generated tokens")?;
    let content = prettyplease::unparse(&ast);

    // Wrap in a module header
    let full_content = format!(
        "// @generated — do not edit. Run `cargo xtask sync-openapi-client` to regenerate.\n\
         #![allow(clippy::all, unused_imports, dead_code)]\n\
         {content}"
    );

    if check {
        let existing = fs::read_to_string(&out_path).unwrap_or_default();
        if existing != full_content {
            bail!(
                "Generated openapi-client types are stale at {}.\n\
                 Run `cargo xtask sync-openapi-client` to regenerate, then commit.",
                out_path.display()
            );
        }
        println!("sync-openapi-client: generated types up to date");
    } else {
        if let Some(parent) = out_path.parent() {
            fs::create_dir_all(parent)?;
        }
        fs::write(&out_path, &full_content)
            .with_context(|| format!("writing {}", out_path.display()))?;
        println!("wrote {}", out_path.display());
    }

    // Also write generated/mod.rs
    let mod_path = out_path.parent().unwrap().join("mod.rs");
    let mod_content = "pub mod types;\npub use types::*;\n".to_string();
    if check {
        let existing = fs::read_to_string(&mod_path).unwrap_or_default();
        if existing != mod_content {
            bail!("Generated openapi-client mod.rs is stale. Run `cargo xtask sync-openapi-client`.");
        }
    } else {
        fs::write(&mod_path, &mod_content)?;
        println!("wrote {}", mod_path.display());
    }

    Ok(())
}
```
