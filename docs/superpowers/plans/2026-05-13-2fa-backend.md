# 2FA for Password Auth — Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or
> superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add TOTP + email OTP two-factor authentication to the password login path, with per-tenant
enforcement, recovery codes, and restricted-session gating.

**Architecture:** Two-phase challenge: `POST /auth/login` → 202 MfaChallengeResponse (hashed token in
`mfa_challenges` table) → `POST /auth/mfa/verify` → 200 AuthResponse. Restricted "setup-required" JWT issued
when enforcement is on and user is unenrolled. A `SetupRequired(bool)` Axum extension in `require_auth`
gates non-enrollment routes with 403.

**Tech Stack:** Rust 2024, Axum 0.7, SeaORM 2.0-rc, SQLite + Postgres, `totp-rs` 6, `argon2` 0.5,
`sha2` 0.10, `base64` 0.22, `rand` 0.9, `time` 0.3. Quality gates: `cargo fmt --all`,
`cargo clippy --all-targets --all-features`, `cargo test --all-features`, `cargo deny check`.

```rust
use totp_rs::{Algorithm, Secret, TOTP};

/// Generate a new TOTP base32 secret suitable for storing in the DB.
pub fn generate_totp_secret() -> String {
    totp_rs::Secret::generate_secret().to_encoded().to_string()
}

/// Build the `otpauth://totp/` URI to encode into a QR code.
/// Returns `None` if the secret is not valid base32 (should not happen — secrets are
/// generated by `generate_totp_secret()` which produces valid base32).
pub fn build_otpauth_uri(secret: &str, user_email: &str, issuer: &str) -> Option<String> {
    build_totp(secret).ok().map(|totp| totp.get_url(user_email, issuer))
}

/// Verify a 6-digit TOTP code with skew=1 (±30 s window).
///
/// Returns `Some(step)` — the TOTP counter index the code matched — on success,
/// or `None` on failure. Callers must persist `step` in `user_totp.last_used_step`
/// and reject any future code with `step <= last_used_step` (RFC 6238 §5.2 replay prevention).
pub fn verify_totp_code(secret: &str, code: &str) -> Option<i64> {
    let Ok(totp) = build_totp(secret) else {
        return None;
    };
    let now_secs = std::time::SystemTime::now()
        .duration_since(std::time::UNIX_EPOCH)
        .unwrap_or_default()
        .as_secs();
    let current_step = (now_secs / 30) as i64;
    // Check current step and ±1 skew window (matches TOTP skew=1 in build_totp)
    for delta in [-1i64, 0, 1] {
        let step = current_step + delta;
        if step < 0 {
            continue;
        }
        let step_time = (step as u64) * 30;
        if let Ok(expected) = totp.generate(step_time) {
            if expected == code {
                return Some(step);
            }
        }
    }
    None
}

fn build_totp(secret: &str) -> Result<TOTP, totp_rs::TotpUrlError> {
    let bytes = Secret::Encoded(secret.to_string())
        .to_bytes()
        .map_err(|_| totp_rs::TotpUrlError::Secret("invalid base32".to_string()))?;
    TOTP::new(Algorithm::SHA1, 6, 1, 30, bytes)
}
```

```rust
use argon2::password_hash::rand_core::OsRng;
use argon2::password_hash::{PasswordHash, PasswordHasher, PasswordVerifier, SaltString};
use argon2::Argon2;
use rand::Rng;
use rootcause::prelude::*;
use sea_orm::{
    ActiveModelTrait, ColumnTrait, DatabaseConnection, EntityTrait, QueryFilter, Set,
    TransactionTrait,
};
use time::OffsetDateTime;
use uptrakit_shared_db::entity::prelude::*;
use uptrakit_shared_db::entity::{mfa_challenge, user_recovery_code};

use super::token::{generate_secure_token, hash_token};
use super::{AuthError, Result};

pub const RECOVERY_CODE_CHARSET: &str = "ABCDEFGHJKLMNPQRSTUVWXYZ23456789";
const MFA_CHALLENGE_TTL_SECS: i64 = 300; // 5 minutes
const MAX_MFA_ATTEMPTS: i32 = 5;

/// Plaintext MFA token + the user_id it was created for.
pub struct NewMfaChallenge {
    pub plaintext_token: String,
    pub user_id: uuid::Uuid,
}

/// Create a new MFA challenge row in the DB. Returns the plaintext token to send to the client.
pub async fn create_mfa_challenge(
    db: &impl sea_orm::ConnectionTrait,
    user_id: uuid::Uuid,
) -> Result<String> {
    let plaintext = generate_secure_token()?;
    let token_hash = hash_token(&plaintext);
    let now = OffsetDateTime::now_utc();

    mfa_challenge::ActiveModel {
        id: Set(uuid::Uuid::now_v7()),
        user_id: Set(user_id),
        token_hash: Set(token_hash),
        email_code_hash: Set(None),
        attempt_count: Set(0),
        expires_at: Set(now + time::Duration::seconds(MFA_CHALLENGE_TTL_SECS)),
        consumed_at: Set(None),
        created_at: Set(now),
    }
    .insert(db)
    .await
    .context_to()?;

    Ok(plaintext)
}

/// Look up and validate an MFA challenge by plaintext token.
///
/// Returns the model if the challenge is valid (exists, not consumed, not expired).
/// Must be called inside a `BEGIN IMMEDIATE` transaction (see `mfa_verify` handler).
pub async fn load_valid_challenge(
    db: &impl sea_orm::ConnectionTrait,
    plaintext_token: &str,
) -> Result<mfa_challenge::Model> {
    let token_hash = hash_token(plaintext_token);
    let now = OffsetDateTime::now_utc();

    let challenge = MfaChallenge::find()
        .filter(mfa_challenge::Column::TokenHash.eq(&token_hash))
        .one(db)
        .await
        .context_to()?
        .ok_or_else(|| report!(AuthError::MfaChallengeNotFound))?;

    if challenge.consumed_at.is_some() {
        return Err(report!(AuthError::MfaChallengeNotFound));
    }
    if now >= challenge.expires_at {
        return Err(report!(AuthError::MfaChallengeExpired));
    }
    if challenge.attempt_count >= MAX_MFA_ATTEMPTS {
        return Err(report!(AuthError::MfaChallengeExhausted));
    }

    Ok(challenge)
}

/// Increment attempt_count. If >= MAX_MFA_ATTEMPTS, also poison the challenge (set consumed_at).
/// Returns true if the challenge is now exhausted.
pub async fn record_failed_attempt(
    db: &impl sea_orm::ConnectionTrait,
    challenge: &mfa_challenge::Model,
) -> Result<bool> {
    use sea_orm::{IntoActiveModel, Set};
    let now = OffsetDateTime::now_utc();
    let new_count = challenge.attempt_count + 1;
    let exhausted = new_count >= MAX_MFA_ATTEMPTS;

    let mut active: mfa_challenge::ActiveModel = challenge.clone().into_active_model();
    active.attempt_count = Set(new_count);
    if exhausted {
        active.consumed_at = Set(Some(now));
    }
    active.update(db).await.context_to()?;

    Ok(exhausted)
}

/// Mark a challenge as consumed (success).
pub async fn consume_challenge(
    db: &impl sea_orm::ConnectionTrait,
    challenge: &mfa_challenge::Model,
) -> Result<()> {
    use sea_orm::{IntoActiveModel, Set};
    let mut active: mfa_challenge::ActiveModel = challenge.clone().into_active_model();
    active.consumed_at = Set(Some(OffsetDateTime::now_utc()));
    active.update(db).await.context_to()?;
    Ok(())
}

/// Generate a 6-digit zero-padded email OTP code.
pub fn generate_email_otp() -> String {
    let n: u32 = OsRng.gen_range(0..1_000_000);
    format!("{n:06}")
}

/// Hash an email OTP code with Argon2id (same params as password hashing).
pub fn hash_email_otp(code: &str) -> Result<String> {
    let salt = SaltString::generate(&mut OsRng);
    let argon2 = Argon2::default();
    let hash = argon2
        .hash_password(code.as_bytes(), &salt)
        .map_err(|e| report!(AuthError::PasswordHash(e)))?
        .to_string();
    Ok(hash)
}

/// Verify an email OTP code against its stored hash.
pub fn verify_email_otp(code: &str, hash: &str) -> Result<bool> {
    let parsed = PasswordHash::new(hash).map_err(|e| report!(AuthError::PasswordHash(e)))?;
    Ok(Argon2::default()
        .verify_password(code.as_bytes(), &parsed)
        .is_ok())
}

/// Store the email OTP hash in the challenge row.
pub async fn store_email_otp_hash(
    db: &impl sea_orm::ConnectionTrait,
    challenge: &mfa_challenge::Model,
    code_hash: String,
) -> Result<()> {
    use sea_orm::{IntoActiveModel, Set};
    let mut active: mfa_challenge::ActiveModel = challenge.clone().into_active_model();
    active.email_code_hash = Set(Some(code_hash));
    active.update(db).await.context_to()?;
    Ok(())
}

/// Generate 8 unique 10-char recovery codes (plaintext).
pub fn generate_recovery_codes() -> Vec<String> {
    let charset: Vec<char> = RECOVERY_CODE_CHARSET.chars().collect();
    let mut rng = OsRng;
    (0..8)
        .map(|_| {
            (0..10)
                .map(|_| charset[rng.gen_range(0..charset.len())])
                .collect()
        })
        .collect()
}

/// Hash a single recovery code with Argon2id.
pub fn hash_recovery_code(code: &str) -> Result<String> {
    hash_email_otp(code) // same Argon2id params
}

/// Find the first unused recovery code that matches `plaintext`. Returns the row id if found.
///
/// Must run inside `spawn_blocking` — each Argon2id verify takes ~100 ms.
pub fn find_matching_recovery_code(
    codes: &[user_recovery_code::Model],
    plaintext: &str,
) -> Option<uuid::Uuid> {
    for code in codes.iter().filter(|c| c.used_at.is_none()) {
        let Ok(hash) = PasswordHash::new(&code.code_hash) else {
            continue;
        };
        if Argon2::default()
            .verify_password(plaintext.as_bytes(), &hash)
            .is_ok()
        {
            return Some(code.id);
        }
    }
    None
}

/// Mark a recovery code row as used. Must be called inside a `BEGIN IMMEDIATE` transaction.
pub async fn consume_recovery_code(
    db: &impl sea_orm::ConnectionTrait,
    code_id: uuid::Uuid,
) -> Result<()> {
    use uptrakit_shared_db::entity::user_recovery_code;
    user_recovery_code::Entity::update_many()
        .col_expr(
            user_recovery_code::Column::UsedAt,
            sea_orm::sea_query::Expr::value(OffsetDateTime::now_utc()),
        )
        .filter(user_recovery_code::Column::Id.eq(code_id))
        .exec(db)
        .await
        .context_to()?;
    Ok(())
}

/// Delete all existing recovery codes for a user and insert 8 new ones.
///
/// Must be called inside a `BEGIN IMMEDIATE` transaction — the delete+insert pair must
/// be atomic to prevent a race window where a user has zero codes.
pub async fn replace_recovery_codes(
    db: &impl sea_orm::ConnectionTrait,
    user_id: uuid::Uuid,
    plaintext_codes: &[String],
) -> Result<()> {
    UserRecoveryCode::delete_many()
        .filter(user_recovery_code::Column::UserId.eq(user_id))
        .exec(db)
        .await
        .context_to()?;

    let now = OffsetDateTime::now_utc();
    for code in plaintext_codes {
        let hash = hash_recovery_code(code)?;
        user_recovery_code::ActiveModel {
            id: Set(uuid::Uuid::now_v7()),
            user_id: Set(user_id),
            code_hash: Set(hash),
            created_at: Set(now),
            used_at: Set(None),
        }
        .insert(db)
        .await
        .context_to()?;
    }

    Ok(())
}
```

```rust
use serde::{Deserialize, Serialize};

use crate::validation::{Validate, ValidationError};

/// Identifies the MFA method used in a challenge verification request.
///
/// Deserialised from HTTP bodies — uses infallible custom `Deserialize` with
/// `Other(String)` so unknown methods never cause a 400 parse error
/// (handler match arm returns false instead). Loses `Copy` due to `String`.
#[non_exhaustive]
#[derive(Clone, Debug, PartialEq, Eq, Serialize)]
#[serde(rename_all = "snake_case")]
pub enum MfaMethod {
    Totp,
    Email,
    RecoveryCode,
    /// Unknown method from a future client; verified as false.
    Other(String),
}

impl<'de> serde::Deserialize<'de> for MfaMethod {
    fn deserialize<D: serde::Deserializer<'de>>(d: D) -> Result<Self, D::Error> {
        let s = String::deserialize(d)?;
        Ok(match s.as_str() {
            "totp" => Self::Totp,
            "email" => Self::Email,
            "recovery_code" => Self::RecoveryCode,
            _ => Self::Other(s),
        })
    }
}

impl MfaMethod {
    pub fn as_str(&self) -> &str {
        match self {
            Self::Totp => "totp",
            Self::Email => "email",
            Self::RecoveryCode => "recovery_code",
            Self::Other(s) => s.as_str(),
        }
    }
}

impl std::fmt::Display for MfaMethod {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        f.write_str(self.as_str())
    }
}
```

```rust
use sea_orm::{ColumnTrait, EntityTrait, QueryFilter};

use uptrakit_web_api_types::auth::AuthResponse;
use uptrakit_web_api_types::mfa::{MfaVerifyRequest, MfaEmailRequest, MfaMethod};
use uptrakit_web_api_types::validation::Validate;

use crate::AppState;
use crate::auth::session::{create_session_tokens, build_auth_response};
use crate::error_response::error_response;
use uptrakit_web_api_auth::auth::mfa_challenge::{
    consume_challenge, consume_recovery_code, create_mfa_challenge,
    find_matching_recovery_code, generate_email_otp, hash_email_otp,
    load_valid_challenge, record_failed_attempt, replace_recovery_codes,
    store_email_otp_hash, verify_email_otp,

use uptrakit_web_api_auth::auth::totp::verify_totp_code;

/// `POST /api/v1/auth/mfa/verify`
pub async fn mfa_verify(
    State(state): State<Arc<AppState>>,
    Json(req): Json<MfaVerifyRequest>,
) -> Response {
    if let Err(e) = req.validate() {
        return error_response(StatusCode::BAD_REQUEST, &e.message);
    }

    let db = state.db();

    // Open BEGIN IMMEDIATE transaction — load+validate+mutate the challenge must be atomic.
    // On SQLite, a bare SELECT followed by an UPDATE across two round-trips causes
    // SQLITE_BUSY_SNAPSHOT if another connection commits between them (project standard,
    // docs/development/coding-standards.md "Database Query Patterns").
    use sea_orm::{SqliteTransactionMode, TransactionOptions, TransactionTrait};
    let txn = match db
        .begin_with_options(TransactionOptions {
            sqlite_transaction_mode: Some(SqliteTransactionMode::Immediate),
            ..Default::default()
        })
        .await
    {
        Ok(t) => t,
        Err(e) => {
            tracing::error!(error = %e, "Failed to begin MFA transaction");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    // Load and validate challenge (returns 401 on any invalid state)
    let challenge = match load_valid_challenge(&txn, &req.mfa_token).await {
        Ok(c) => c,
        Err(e) => {
            tracing::debug!(error = %e, "MFA challenge lookup failed");
            let _ = txn.rollback().await;
            return error_response(StatusCode::UNAUTHORIZED, "Invalid or expired MFA token");
        }
    };

    let user_id = challenge.user_id;

    // All challenge reads and writes go through &txn (BEGIN IMMEDIATE opened above).
    let code_valid = match req.method {
        MfaMethod::Totp => {
            // Fetch TOTP row inside the transaction so the last_used_step read and write
            // are serialised against concurrent verifications (prevents replay window).
            let totp_row = UserTotp::find()
                .filter(user_totp::Column::UserId.eq(user_id))
                .filter(user_totp::Column::IsActive.eq(true))
                .one(&txn)
                .await;

            match totp_row {
                Ok(Some(row)) => {
                    let secret = match row.secret.decrypt() {
                        Ok(s) => s,
                        Err(e) => {
                            tracing::error!(user_id = %user_id, error = %e, "TOTP secret decrypt failed");
                            let _ = txn.rollback().await;
                            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                        }
                    };
                    // verify_totp_code now returns Option<i64> (the matched step index).
                    // Check anti-replay: reject codes at or below the last-used step.
                    let matched_step = verify_totp_code(&secret, &req.code);
                    if let Some(step) = matched_step {
                        let last = row.last_used_step.unwrap_or(-1);
                        if step <= last {
                            tracing::warn!(user_id = %user_id, step, last, "TOTP replay attempt rejected");
                            false
                        } else {
                            // Update last_used_step atomically inside the txn
                            let mut active: user_totp::ActiveModel = row.into_active_model();
                            active.last_used_step = Set(Some(step));
                            if let Err(e) = active.update(&txn).await {
                                tracing::error!(error = %e, "Failed to update TOTP last_used_step");
                                let _ = txn.rollback().await;
                                return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                            }
                            true
                        }
                    } else {
                        false
                    }
                }
                _ => false,
            }
        }
        MfaMethod::Email => {
            let Some(ref hash) = challenge.email_code_hash else {
                let _ = txn.rollback().await;
                return error_response(
                    StatusCode::BAD_REQUEST,
                    "No email OTP has been sent for this challenge",
                );
            };
            let hash = hash.clone();
            let code = req.code.clone();
            match spawn_blocking(move || verify_email_otp(&code, &hash)).await {
                Ok(Ok(true)) => true,
                Ok(Ok(false)) => false,
                Ok(Err(e)) => {
                    tracing::error!(error = %e, "Email OTP verification error");
                    false
                }
                Err(e) => {
                    tracing::error!(error = %e, "spawn_blocking join error in email OTP verify");
                    let _ = txn.rollback().await;
                    return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                }
            }
        }
        MfaMethod::RecoveryCode => {
            let codes = match UserRecoveryCode::find()
                .filter(user_recovery_code::Column::UserId.eq(user_id))
                .all(&txn)
                .await
            {
                Ok(c) => c,
                Err(e) => {
                    tracing::error!(error = %e, "Failed to load recovery codes");
                    let _ = txn.rollback().await;
                    return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                }
            };

            let plaintext = req.code.clone();
            let matched_id = match spawn_blocking(move || find_matching_recovery_code(&codes, &plaintext)).await {
                Ok(id) => id,
                Err(e) => {
                    tracing::error!(error = %e, "spawn_blocking join error in recovery code match");
                    let _ = txn.rollback().await;
                    return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                }
            };

            if let Some(code_id) = matched_id {
                if let Err(e) = consume_recovery_code(&txn, code_id).await {
                    tracing::error!(error = %e, "Failed to consume recovery code");
                    let _ = txn.rollback().await;
                    return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
                }
                true
            } else {
                false
            }
        }
        _ => false,
    };

    if !code_valid {
        let exhausted = match record_failed_attempt(&txn, &challenge).await {
            Ok(e) => e,
            Err(e) => {
                tracing::error!(error = %e, "Failed to record MFA attempt");
                false
            }
        };

        // Commit the attempt_count increment (or exhaustion) before returning
        if let Err(e) = txn.commit().await {
            tracing::error!(error = %e, "Failed to commit MFA attempt record");
        }

        let action = if exhausted {
            uptrakit_audit_log::AuditActionType::AUTH_MFA_CHALLENGE_EXHAUSTED
        } else {
            uptrakit_audit_log::AuditActionType::AUTH_MFA_FAILED
        };

        if let Ok(entry) = uptrakit_audit_log::AuditEntry::builder(action)
            .tenant_scope(state.default_tenant_id)
            .actor(uptrakit_audit_log::AuditActorType::User, Some(user_id))
            .target("user", user_id.to_string(), None)
            .outcome(uptrakit_audit_log::AuditOutcome::Denied)
            .details(serde_json::json!({
                "method": req.method.as_str(),
                "attempt_count": challenge.attempt_count + 1,
            }))
            .build()
        {
            state.audit_emitter.emit_best_effort(entry);
        }

        return error_response(StatusCode::UNAUTHORIZED, "Invalid MFA code");
    }

    // Success: consume challenge and commit the entire transaction
    if let Err(e) = consume_challenge(&txn, &challenge).await {
        tracing::error!(error = %e, "Failed to consume MFA challenge");
        let _ = txn.rollback().await;
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    if let Err(e) = txn.commit().await {
        tracing::error!(error = %e, "Failed to commit MFA success transaction");
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    // Post-commit audits (use outer db — txn is consumed).
    if matches!(req.method, MfaMethod::RecoveryCode) {
        let remaining = UserRecoveryCode::find()
            .filter(user_recovery_code::Column::UserId.eq(user_id))
            .filter(user_recovery_code::Column::UsedAt.is_null())
            .count(db)
            .await
            .unwrap_or_else(|e| {
                tracing::warn!(error = %e, "Failed to count remaining recovery codes for audit");
                0
            });
        if let Ok(entry) = uptrakit_audit_log::AuditEntry::builder(
            uptrakit_audit_log::AuditActionType::AUTH_MFA_RECOVERY_USED,
        )
        .tenant_scope(state.default_tenant_id)
        .actor(uptrakit_audit_log::AuditActorType::User, Some(user_id))
        .target("user", user_id.to_string(), None)
        .outcome(uptrakit_audit_log::AuditOutcome::Success)
        .details(serde_json::json!({ "remaining_count": remaining }))
        .build()
        {
            state.audit_emitter.emit_best_effort(entry);
        }
    }

    let auth_response = match build_full_session(&state, user_id).await {
        Ok(r) => r,
        Err(e) => {
            tracing::error!(error = %e, "Failed to build session after MFA");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    if let Ok(entry) = uptrakit_audit_log::AuditEntry::builder(
        uptrakit_audit_log::AuditActionType::AUTH_MFA_VERIFIED,
    )
    .tenant_scope(state.default_tenant_id)
    .actor(uptrakit_audit_log::AuditActorType::User, Some(user_id))
    .target("user", user_id.to_string(), None)
    .outcome(uptrakit_audit_log::AuditOutcome::Success)
    .details(serde_json::json!({ "method": req.method.as_str() }))
    .build()
    {
        state.audit_emitter.emit_best_effort(entry);
    }

    Json(auth_response).into_response()
}

/// `POST /api/v1/auth/mfa/email` — send email OTP
pub async fn mfa_send_email(
    State(state): State<Arc<AppState>>,
    Json(req): Json<MfaEmailRequest>,
) -> Response {
    use uptrakit_plugin_infrastructure_registry::TransactionalEmailError;

    if let Err(e) = req.validate() {
        return error_response(StatusCode::BAD_REQUEST, &e.message);
    }

    let db = state.db();

    let challenge = match load_valid_challenge(db, &req.mfa_token).await {
        Ok(c) => c,
        Err(_) => return error_response(StatusCode::UNAUTHORIZED, "Invalid or expired MFA token"),
    };

    // Load user email
    let user = match uptrakit_shared_db::entity::prelude::User::find_by_id(challenge.user_id)
        .one(db)
        .await
    {
        Ok(Some(u)) => u,
        _ => return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error"),
    };

    let email_str = user.email.to_string();
    if email_str.is_empty() {
        return error_response(StatusCode::BAD_REQUEST, "No email address on account");
    }

    // Generate code, hash it in spawn_blocking
    let code = generate_email_otp();
    let code_for_hash = code.clone();
    let hash = match spawn_blocking(move || hash_email_otp(&code_for_hash)).await {
        Ok(Ok(h)) => h,
        _ => return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error"),
    };

    if let Err(e) = store_email_otp_hash(db, &challenge, hash).await {
        tracing::error!(error = %e, "Failed to store email OTP hash");
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    // Use default tenant_db (email plugin requires TenantDb)
    let tenant_db = state.tenant_db(state.default_tenant_id);
    let result = state
        .plugin
        .plugin_ops
        .send_transactional_email(
            &tenant_db,
            &email_str,
            "Your uptrakit login code",
            &format!("Your login code is: {code}\n\nValid for 5 minutes. Do not share."),
            &format!(
                "<p>Your login code is: <strong>{code}</strong></p>\
                 <p>Valid for 5 minutes. Do not share this code.</p>"
            ),
        )
        .await;

    match result {
        Ok(()) => StatusCode::OK.into_response(),
        Err(TransactionalEmailError::NotConfigured) => {
```

```rust
/// `POST /api/v1/auth/me/2fa/totp/enroll` — begin enrollment (accessible from setup_required)
pub async fn totp_enroll(
    State(state): State<Arc<AppState>>,
    Extension(user): Extension<AuthenticatedUser>,
) -> Response {
    let db = state.db();
    let user_id = user.user_id;

    let secret = generate_totp_secret();
    let encrypted = match uptrakit_crypto::EncryptedString::encrypt(&secret) {
        Ok(e) => e,
        Err(e) => {
            tracing::error!(error = %e, "Failed to encrypt TOTP secret");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    // Upsert pending row in a BEGIN IMMEDIATE transaction.
    // Without atomicity, a concurrent totp_confirm could read between the delete and insert.
    use sea_orm::{SqliteTransactionMode, TransactionOptions, TransactionTrait};
    let enroll_txn = match db
        .begin_with_options(TransactionOptions {
            sqlite_transaction_mode: Some(SqliteTransactionMode::Immediate),
            ..Default::default()
        })
        .await
    {
        Ok(t) => t,
        Err(e) => {
            tracing::error!(error = %e, "Failed to begin TOTP enroll transaction");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    if let Err(e) = UserTotp::delete_many()
        .filter(user_totp::Column::UserId.eq(user_id))
        .filter(user_totp::Column::IsActive.eq(false))
        .exec(&enroll_txn)
        .await
    {
        tracing::error!(user_id = %user_id, error = %e, "Failed to delete pending TOTP row");
        let _ = enroll_txn.rollback().await;
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    if let Err(e) = user_totp::ActiveModel {
        id: Set(uuid::Uuid::now_v7()),
        user_id: Set(user_id),
        secret: Set(encrypted),
        is_active: Set(false),
        enrolled_at: Set(None),
        last_used_step: Set(None),
        created_at: Set(OffsetDateTime::now_utc()),
    }
    .insert(&enroll_txn)
    .await
    {
        tracing::error!(user_id = %user_id, error = %e, "Failed to insert pending TOTP row");
        let _ = enroll_txn.rollback().await;
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    if let Err(e) = enroll_txn.commit().await {
        tracing::error!(error = %e, "Failed to commit TOTP enroll transaction");
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    // Load user email for issuer label
    let user_row = match User::find_by_id(user_id).one(db).await {
        Ok(Some(u)) => u,
        _ => return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error"),
    };

    let otpauth_uri = match build_otpauth_uri(&secret, &user_row.email.to_string(), "uptrakit") {
        Some(uri) => uri,
        None => {
            tracing::error!(user_id = %user_id, "Failed to build otpauth URI — invalid TOTP secret");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    Json(TotpEnrollResponse {
        otpauth_uri,
        secret,
    })
    .into_response()
}

/// `POST /api/v1/auth/me/2fa/totp/confirm` — confirm TOTP code, activate 2FA
///
/// Accessible from setup_required sessions. On success, issues new full-session tokens.
pub async fn totp_confirm(
    State(state): State<Arc<AppState>>,
    Extension(user): Extension<AuthenticatedUser>,
    Extension(setup_required): Extension<crate::middleware::require_auth::SetupRequired>,
    Json(req): Json<TotpConfirmRequest>,
) -> Response {
    if let Err(e) = req.validate() {
        return error_response(StatusCode::BAD_REQUEST, &e.message);
    }

    let db = state.db();
    let user_id = user.user_id;

    let totp_row = match UserTotp::find()
        .filter(user_totp::Column::UserId.eq(user_id))
        .filter(user_totp::Column::IsActive.eq(false))
        .one(db)
        .await
    {
        Ok(Some(r)) => r,
        _ => return error_response(StatusCode::BAD_REQUEST, "No pending TOTP enrollment"),
    };

    let secret = match totp_row.secret.decrypt() {
        Ok(s) => s,
        Err(e) => {
            tracing::error!(error = %e, "TOTP secret decrypt failed");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    let matched_step = verify_totp_code(&secret, &req.code);
    if matched_step.is_none() {
        return error_response(StatusCode::UNPROCESSABLE_ENTITY, "Invalid TOTP code");
    }
    let matched_step = matched_step.expect("checked above");

    // Activate TOTP + store recovery codes atomically in BEGIN IMMEDIATE transaction.
    // Without atomicity: if DB fails between activate and code storage, user has active 2FA
    // but zero recovery codes and is permanently locked out if they lose their device.
    use sea_orm::{SqliteTransactionMode, TransactionOptions, TransactionTrait};
    let confirm_txn = match db
        .begin_with_options(TransactionOptions {
            sqlite_transaction_mode: Some(SqliteTransactionMode::Immediate),
            ..Default::default()
        })
        .await
    {
        Ok(t) => t,
        Err(e) => {
            tracing::error!(error = %e, "Failed to begin TOTP confirm transaction");
            return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
        }
    };

    let mut active: user_totp::ActiveModel = totp_row.into_active_model();
    active.is_active = Set(true);
    active.enrolled_at = Set(Some(OffsetDateTime::now_utc()));
    active.last_used_step = Set(Some(matched_step));
    if let Err(e) = active.update(&confirm_txn).await {
        tracing::error!(error = %e, "Failed to activate TOTP");
        let _ = confirm_txn.rollback().await;
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    // Generate and store recovery codes
    let codes = generate_recovery_codes();
    let codes_for_store = codes.clone();
    if let Err(e) = replace_recovery_codes(&confirm_txn, user_id, &codes_for_store).await {
        tracing::error!(error = %e, "Failed to store recovery codes");
        let _ = confirm_txn.rollback().await;
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    if let Err(e) = confirm_txn.commit().await {
        tracing::error!(error = %e, "Failed to commit TOTP enrollment transaction");
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    // Emit AUTH_MFA_ENROLLED
    if let Ok(entry) = uptrakit_audit_log::AuditEntry::builder(
        uptrakit_audit_log::AuditActionType::AUTH_MFA_ENROLLED,
    )
    .tenant_scope(state.default_tenant_id)
    .actor(uptrakit_audit_log::AuditActorType::User, Some(user_id))
    .target("user", user_id.to_string(), None)
    .outcome(uptrakit_audit_log::AuditOutcome::Success)
    .details(serde_json::json!({ "user_id": user_id }))
    .build()
    {
        state.audit_emitter.emit_best_effort(entry);
    }

    // If this was a restricted session, issue new full-session tokens
    let session = if setup_required.0 {
        match build_full_session(&state, user_id).await {
            Ok(r) => Some(r),
            Err(e) => {
                tracing::error!(error = %e, "Failed to build post-enrollment session");
                return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
            }
        }
    } else {
        None
    };

    Json(TotpConfirmResponse {
        recovery_codes: codes,
        session,
    })
    .into_response()
}

/// `POST /api/v1/auth/me/2fa/totp/disable` — requires full session + re-auth
pub async fn totp_disable(
    State(state): State<Arc<AppState>>,
    FullSessionUser(user): FullSessionUser,
    Json(req): Json<DisableTotpRequest>,
) -> Response {

        return error_response(StatusCode::BAD_REQUEST, &e.message);
    }

    }

    let deleted = UserTotp::delete_many()

    {
        tracing::error!(user_id = %user_id, error = %e, "Failed to delete recovery codes on TOTP disable");
        return error_response(StatusCode::INTERNAL_SERVER_ERROR, "Internal error");
    }

    if let Ok(entry) = uptrakit_audit_log::AuditEntry::builder(
        uptrakit_audit_log::AuditActionType::AUTH_MFA_DISABLED,
    )
    .tenant_scope(state.default_tenant_id)

}

/// Shared re-authentication helper: verifies password OR current TOTP code.
async fn re_auth_ok(
    state: &AppState,
    user_id: uuid::Uuid,
    password: Option<&uptrakit_shared_types::SecretString>,
    totp_code: Option<&str>,
) -> bool {
    let db = state.db();

    if let Some(pw) = password {
        let user_row = match User::find_by_id(user_id).one(db).await {
            Ok(Some(u)) => u,
            _ => return false,
        };
        let Some(ref hash) = user_row.password_hash else {
            return false;
        };
        let pw_str = pw.expose_secret().to_string();
        let hash_str = hash.expose_secret().to_string();
        return spawn_blocking(move || {
            verify_password(&pw_str, &hash_str).unwrap_or(false)
        })
        .await
        .unwrap_or(false);
    }

    if let Some(code) = totp_code {
        let totp_row = match UserTotp::find()
            .filter(user_totp::Column::UserId.eq(user_id))
            .filter(user_totp::Column::IsActive.eq(true))
            .one(db)
            .await
        {
            Ok(Some(r)) => r,
            _ => return false,
        };
        let secret = match totp_row.secret.decrypt() {
            Ok(s) => s,
            Err(_) => return false,
        };
        let Some(step) = verify_totp_code(&secret, code) else {
            return false;
        };
        // Enforce monotonicity: reject replay within the same window.
        let last = totp_row.last_used_step.unwrap_or(-1);
        if step <= last {
            tracing::warn!(user_id = %user_id, step, last, "TOTP replay attempt in re_auth_ok");
            return false;
        }
        // Persist the used step so this code can't be replayed again.
        let mut active: user_totp::ActiveModel = totp_row.into_active_model();
        active.last_used_step = Set(Some(step));
        // Ignore update errors — re_auth_ok is best-effort; worst case is a replay in the
        // 30-second window before the row is updated by the next request.
        let _ = active.update(db).await;
        return true;
    }

    false
}
```

```markdown
# Setting Up Two-Factor Authentication

Two-factor authentication (2FA) adds a second verification step to your login, protecting
your account even if your password is compromised.

## Set up an authenticator app

1. Go to **Profile → Security**.
2. Click **Set up authenticator app**.
3. Scan the QR code with an authenticator app (Google Authenticator, Authy, 1Password, etc.).
4. Enter the 6-digit code shown in the app to confirm.
5. Save your recovery codes somewhere safe — you will not see them again.

## Log in with 2FA

After entering your password, you will be prompted for your 6-digit code. Open your
authenticator app and enter the current code.

If you cannot access your authenticator app, click **Use email instead** (requires email
delivery to be configured) or enter one of your **recovery codes**.

## Recovery codes

Recovery codes are single-use backup codes. Each code can only be used once. After using
a recovery code, generate new codes from **Profile → Security → Recovery codes**.

## Disable 2FA

Go to **Profile → Security** and click **Disable 2FA**. You will need to confirm with your
password or current authenticator code.
```

```markdown
# Enforcing 2FA for All Operators

Administrators can require every password-authenticated user in a tenant to enroll in 2FA
before accessing the application.

## Enable enforcement

1. Go to **Settings → Authentication**.
2. Toggle **Require two-factor authentication** to on.
3. Click **Save**.

Once enabled, users who log in without 2FA enrolled will receive a restricted session. They
can only access the 2FA enrollment flow (`/api/v1/auth/me/2fa/*`). All other routes return
`403 { "error": "2fa_setup_required" }` until enrollment is completed.

The enforcement toggle requires the refresh token handler to re-check enrollment state.
This check is included in the implementation — do not expose the toggle in the UI until
the refresh handler check is deployed. See the spec for details.

OIDC-authenticated users are not affected by this setting. 2FA for OIDC is handled by the
identity provider.
```
