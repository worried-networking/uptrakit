# Responsible AI Use Guidelines

- Treat AI suggestions as recommendations. Critically review and understand any AI-generated code before integrating it.
- Never enter sensitive project data, credentials, or private information into public AI tools.
- Maintain code ownership: you are responsible for correctness, security, and maintainability, even for AI-generated code.
- Mention significant AI-assisted work briefly in the PR description so reviewers know the context.
- Use AI tools to learn patterns, explore ideas, and improve code quality.
- Review AI feedback from tools like CodeRabbit before merging.
- Be mindful of AI biases, especially in naming or user-facing content, and adjust as needed.
