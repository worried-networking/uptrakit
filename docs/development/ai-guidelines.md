# Responsible AI Use Guidelines

- Treat AI suggestions as recommendations. Critically review and understand any AI-generated code before integrating it.
- Never enter sensitive project data, credentials, or private information into public AI tools.
- Maintain code ownership: you are responsible for correctness, security, and maintainability, even for AI-generated code.
- Disclose significant AI-assisted work briefly in the PR description so reviewers know the context. This includes cases where AI materially drafted
  code, tests, documentation, migrations, or user-facing content.
- Use AI tools to learn patterns, explore ideas, and improve code quality.
- Review AI feedback from tools like CodeRabbit before merging.
- Be mindful of AI biases, especially in naming or user-facing content, and adjust as needed.

## Unacceptable AI-Assisted Contributions

- Do not submit code you cannot explain, review, or safely modify yourself.
- Do not paste large AI-generated diffs without validating behavior, edge cases, and affected documentation.
- Do not use AI assistance to bypass normal testing, review, or security scrutiny.
- Do not submit AI-generated content that may copy third-party material without checking license compatibility and originality.
- Do not hide material AI involvement when it would help reviewers understand provenance, risk, or validation depth.
